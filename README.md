# 📝 CP4-MOBILE — App de Notas
Aplicativo mobile de anotações pessoais desenvolvido com **React Native (Expo)** e **Firebase Firestore**, permitindo criar, editar, buscar e excluir notas com persistência em tempo real na nuvem.
---
## 📖 Descrição do Projeto
O **App de Notas** é uma aplicação mobile que funciona como um bloco de notas digital. O usuário pode:
- ✅ Criar notas com título e conteúdo
- ✏️ Editar notas existentes
- 🗑️ Excluir notas
- 🔍 Buscar notas por título
- 🔐 Fazer login/cadastro com e-mail e senha
- ☁️ Todas as notas são salvas no **Firebase Firestore** em tempo real
---
## 🚀 Tecnologias Utilizadas
| Tecnologia | Finalidade |
|---|---|
| **React Native** | Framework mobile multiplataforma |
| **Expo** | Plataforma de desenvolvimento e build |
| **TypeScript** | Tipagem estática |
| **Firebase Auth** | Autenticação de usuários |
| **Firebase Firestore** | Banco de dados NoSQL em tempo real |
| **React Navigation** | Navegação entre telas |

## ⚙️ Como Rodar o Projeto
### Pré-requisitos
- [Node.js](https://nodejs.org/) (v18+)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- [Git](https://git-scm.com/)
### Passo a passo
```bash
# 1. Clone o repositório
git clone https://github.com/SEU-USUARIO/cp4-mobile-notas.git
# 2. Entre na pasta do projeto
cd cp4-mobile-notas
# 3. Instale as dependências
npm install
# 4. Inicie o projeto
npx expo start
```
### Executando no dispositivo
- **Android**: Escaneie o QR Code com o app **Expo Go**
- **iOS**: Escaneie o QR Code com a câmera do iPhone
- **Emulador**: Pressione `a` (Android) ou `i` (iOS) no terminal
